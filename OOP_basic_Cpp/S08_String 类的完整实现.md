# String 类的完整实现（复习）

> 本文档系统性地复习了带指针成员的 String 类的完整实现过程，涵盖**构造函数、析构函数、拷贝构造函数、拷贝赋值运算符**这四大核心函数的实现细节与设计考量。这是 C++ 中“三大函数（Big Three）”的经典实战案例。

## 一、String 类的整体设计

### 1.1 为什么 String 类必须用指针？

字符串的长度是不固定的 —— `"hello"` 只有 5 个字符，而 `"hello world"` 有 11 个字符。如果使用固定大小的数组（如 `char data[100]`），要么浪费大量内存，要么无法存储更长的字符串。

使用**动态分配的指针**则灵活得多：需要多长就分配多长，既节省内存又能容纳任意长度的字符串。

### 1.2 String 类的核心结构

```cpp

// string.h —— 防卫式声明
#ifndef _STRING_H_
#define _STRING_H_
#include <cstring>   // 提供 strlen, strcpy
class String {
public:
    // 三大函数：拷贝构造、拷贝赋值、析构
    String(const char* cstr = 0);          // 构造函数（含默认值）
    String(const String& str);             // 拷贝构造函数
    String& operator=(const String& str);  // 拷贝赋值运算符
    ~String();                              // 析构函数
    
    // 辅助函数
    char* get_c_str() const { return m_data; }  // 返回内部指针
    
private:
    char* m_data;  // 指向动态分配的字符数组（含结束符 \0）
};
#endif
```
**设计要点**：

- String 类内部只包含**一个指针成员** `m_data`，在 32 位平台上占 4 字节，64 位平台上占 8 字节
    
- 真正的字符串内容存放在 `m_data` 指向的**动态分配的内存**中
    
- 使用指针而非固定数组，避免了字符串长度的限制
    

## 二、构造函数

构造函数负责在对象创建时分配内存并初始化字符串内容。

### 2.1 函数签名

```cpp

String::String(const char* cstr = 0)
```
**参数设计**：

- **类型**：`const char*` —— 接受一个 C 风格字符串指针
    
- **默认值**：`= 0`（即 `nullptr`）—— 当不传参时，默认构造一个空字符串
    
- **加 `const`**：表示只读输入，函数内部不会修改传入的字符串
    

**无返回类型**：构造函数没有返回值类型（连 `void` 都不写）。

> 📖 **参考**：cppreference 构造函数 —— “构造函数是声明为类名的特殊成员函数，用于初始化对象。”“构造函数没有返回类型。”

### 2.2 实现逻辑

```cpp

inline String::String(const char* cstr = 0)
{
    if (cstr) {
        // 情况1：传入有效字符串
        m_data = new char[strlen(cstr) + 1];  // +1 给结束符 \0
        strcpy(m_data, cstr);
    } else {
        // 情况2：传入空指针（未指定初值）
        m_data = new char[1];    // 分配1个字节
        *m_data = '\0';          // 设为空字符串
    }
}
```
**核心任务**：分配足够的内存空间来存放传入的字符串初值。

**实现步骤**：

|步骤|操作|说明|
|---|---|---|
|① 判断指针有效性|`if (cstr)`|检查传入的指针是否为空|
|② 分配内存|`new char[strlen(cstr) + 1]`|`strlen()` 获取字符串长度（不含 `\0`）；`+1` 存放结束符|
|③ 拷贝内容|`strcpy(m_data, cstr)`|将传入的字符串内容拷贝到新分配的内存中|

**处理无初值的情况**：

- 当传入指针为 `0`（即未指定初值）时，需要创建一个空字符串
    
- 分配 `new char[1]`，一个字符的空间
    
- 设置 `*m_data = '\0'`，形成 C 风格的空字符串
    

> 📖 **参考**：cppreference `std::strlen` —— “返回给定字节字符串的长度，即首个空字符之前的字符数。”`std::strcpy` —— “将从 src 指向的字节字符串复制到 dest 指向的字符数组中。”

**关键注意点**：

- **`strlen(cstr) + 1` 中的 `+1` 绝不能省略**：C 风格字符串必须以 `\0` 结尾，如果不预留空间，`strcpy` 会越界写入，导致**未定义行为**
    
- 使用 `strlen` 和 `strcpy` 需要包含头文件 `<cstring>` 或 `<string.h>`
    
- 建议加上 `inline` 关键字（函数体虽不算极简，但可以建议编译器内联）
    

### 2.3 构造函数设计要点速查

|要点|说明|
|---|---|
|参数类型|`const char*`（只读输入）|
|默认值|`= 0`（支持无参构造）|
|返回类型|无（构造函数不返回值）|
|空间计算|`strlen(cstr) + 1`（多 1 字节给 `\0`）|
|空字符串处理|`new char[1]`，设置 `*m_data = '\0'`|
|头文件|需包含 `<cstring>`|

## 三、析构函数

析构函数负责在对象生命周期结束时释放动态分配的内存。

### 3.1 函数签名

```cpp

String::~String()
```
- 函数名为类名前加波浪号 `~`
    
- 无参数，无返回类型
    
- 每个类只能有一个析构函数
    

> 📖 **参考**：cppreference 析构函数 —— “析构函数是对象生存期终结时调用的特殊成员函数。析构函数的目的是释放对象可能在其生存期内获得的资源。”

### 3.2 实现逻辑

```cpp

inline String::~String()
{
    delete[] m_data;
}
```

**核心任务**：释放构造函数中动态分配的内存，清理资源。

**关键点**：

- 因为构造函数中使用的是 `new[]`（array new）来分配内存，所以析构函数中**必须使用对应的 `delete[]`**（array delete）来释放
    
- 如果写成 `delete m_data`（没有方括号），只会释放第一个字符，导致**内存泄漏**和**未定义行为**
    

### 3.3 析构函数的调用时机

|对象类型|析构函数调用时机|
|---|---|
|栈对象|离开作用域（`{}`）时**自动调用**|
|堆对象|执行 `delete` 时调用|
|全局/静态对象|程序结束时调用|

> 📖 **参考**：cppreference `delete[]` 表达式 —— “数组形式的 `delete` 销毁数组中每个元素，然后解分配整个数组的存储。”

### 3.4 析构函数设计要点速查

|要点|说明|
|---|---|
|函数名|`~类名`|
|参数|无|
|返回类型|无|
|核心操作|`delete[] m_data`|
|对应关系|`new[]` 必须配 `delete[]`|

## 四、拷贝构造函数

拷贝构造函数负责以现有对象为蓝本创建一个新对象（**深拷贝**）。

### 4.1 函数签名

```cpp

String::String(const String& str)
```
**参数设计**：

- **类型**：同类的**引用**（`const String&`）
    
- **加 `const`**：蓝本对象只读，不会被修改
    
- **为什么必须是引用**：如果是按值传递（`String(const String str)`），传递实参时**本身就会再次调用拷贝构造函数**，形成无限递归，导致编译失败
    

> 📖 **参考**：cppreference 拷贝构造函数 —— “拷贝构造函数是用同 class 类型的实参调用的构造函数，它复制实参的内容而不修改实参。”“当对象从另一个相同类型的对象初始化时，调用拷贝构造函数。”

### 4.2 实现逻辑

```cpp

inline String::String(const String& str)
{
    m_data = new char[strlen(str.m_data) + 1];  // 分配足够空间
    strcpy(m_data, str.m_data);                  // 拷贝内容
}
```
**核心任务**：为新对象分配足够的内存，然后将蓝本对象的内容完整拷贝过来。

**实现步骤**：

|步骤|操作|说明|
|---|---|---|
|① 分配内存|`new char[strlen(str.m_data) + 1]`|根据来源字符串的长度分配空间（含 `\0`）|
|② 拷贝内容|`strcpy(m_data, str.m_data)`|将来源字符串的内容拷贝到新内存|

**两种调用方式（完全等价）**：

```cpp

String s2(s1);   // 直接初始化
String s2 = s1;  // 拷贝初始化 —— 虽然用了 =，但 s2 是新创建的对象，仍调用拷贝构造函数
```
### 4.3 深拷贝 vs 浅拷贝
```
||浅拷贝（编译器默认）|深拷贝（我们自己实现）|
|---|---|---|
|操作|复制指针的值（地址）|分配新内存，复制内容|
|结果|两个指针指向**同一块内存**|两个指针指向**各自独立的内存**|
|问题|修改一个影响另一个；重复释放导致崩溃|安全、独立|
```
### 4.4 拷贝构造函数设计要点速查

| 要点   | 说明                       |
| ---- | ------------------------ |
| 函数名  | `类名`（与类同名）               |
| 参数   | `const 类名&`（必须引用，防止无限递归） |
| 返回类型 | 无                        |
| 核心操作 | 分配新内存 → 拷贝内容             |
| 空间计算 | `strlen(str.m_data) + 1` |

## 五、拷贝赋值运算符

拷贝赋值运算符负责将一个已存在的对象的内容赋给另一个已存在的对象。这是三大函数中最复杂的一个。

### 5.1 函数签名

```cpp

String& String::operator=(const String& str)
```
**参数设计**：

- `const String& str`：来源端，只读输入
    

**返回类型**：`String&`（返回当前对象的引用）

- 返回引用是为了支持**连续赋值**（链式操作），如 `a = b = c`
    
- 返回的是 `*this`（当前对象本身）
    

> 📖 **参考**：cppreference 拷贝赋值运算符 —— “拷贝赋值运算符是名字为 `operator=` 的非模板非静态成员函数，它提供一个相同类类型实参就能调用，并且在不修改实参的情况下复制该实参的内容。”

### 5.2 完整实现

```cpp

inline String& String::operator=(const String& str)
{
    // 第一步：自我赋值检测
    if (this == &str) {
        return *this;
    }
    
    // 第二步：释放旧资源
    delete[] m_data;
    
    // 第三步：分配新资源并拷贝内容（深拷贝）
    m_data = new char[strlen(str.m_data) + 1];
    strcpy(m_data, str.m_data);
    
    return *this;
}
```
### 5.3 经典三步走

|步骤|操作|目的|
|---|---|---|
|**① 自我赋值检测**|`if (this == &str) return *this;`|防止自己给自己赋值时崩溃|
|**② 释放旧资源**|`delete[] m_data`|释放左操作数原有的内存，避免内存泄漏|
|**③ 分配新资源并拷贝**|`new[]` + `strcpy`|根据右操作数的大小分配新内存，进行深拷贝|

### 5.4 为什么自我赋值检测必不可少？

**如果不做自我赋值检测，会发生什么？**

```cpp

// ❌ 错误实现（没有自我赋值检测）
String& String::operator=(const String& str)
{
    delete[] m_data;                           // 第一步：释放自己
    m_data = new char[strlen(str.m_data) + 1]; // 第二步：访问 str.m_data
    strcpy(m_data, str.m_data);
    return *this;
}
```
当执行 `s2 = s2`（自我赋值）时：

1. **`delete[] m_data`** —— 释放了 `s2` 唯一的内存块
    
2. **`strlen(str.m_data)`** —— 此时 `str` 就是 `s2`，`str.m_data` 指向的是**已被释放的内存**
    
3. 访问已释放的内存 → **未定义行为**，程序可能崩溃或产生随机结果
    

> **自我赋值检测不仅是效率优化，更是正确性保障**：
> 
> - **效率**：检测到后直接返回，避免不必要的内存操作
>     
> - **正确性（关键）**：如果不做检测，自我赋值会导致程序崩溃
>     

### 5.5 `&` 符号的两种含义

C++ 中 `&` 符号有两种完全不同的含义，取决于出现的位置：

|用法|示例|含义|
|---|---|---|
|**引用声明（类型名后）**|`const String& str`|声明 `str` 是一个引用，绑定到传入的对象|
|**取地址（对象名前）**|`&str`|获取 `str` 对象的地址，返回指针|

**初学者易混淆**：需要根据上下文仔细区分。在 `if (this == &str)` 中，`&str` 是取地址操作。

### 5.6 返回引用与连续赋值

```cpp

String a, b, c;
a = b = c;   // 连续赋值
```
**求值过程**：

1. `b = c` 先执行，返回 `b` 的引用
    
2. `a = (b = c 的返回值)`，即 `a = b`
    

如果返回类型是 `void`（不返回任何值），则 `a = b = c` 无法编译，因为 `b = c` 的结果不是可赋值对象。

**设计思路类比**：与输出操作符重载返回 `ostream&` 以支持 `cout << a << b` 的原理相同。

### 5.7 拷贝赋值运算符设计要点速查

|要点|说明|
|---|---|
|函数名|`operator=`|
|参数|`const 类名&`（只读输入）|
|返回类型|`类名&`（支持链式赋值）|
|返回值|`*this`|
|核心步骤|①自我赋值检测 ②释放旧资源 ③分配新资源 ④拷贝内容|
|自我赋值检测|`if (this == &str) return *this;`|

## 六、辅助函数 `get_c_str()`

```cpp

char* get_c_str() const { return m_data; }
```
**作用**：返回内部的字符指针，方便用户获取字符串内容（如打印、与 C 风格字符串交互）。

**设计要点**：

- **加 `const`**：这个函数不会修改对象的数据，符合 `const` 正确性原则
    
- **类内定义**：函数体简单，直接在类内定义，编译器会将其视为 `inline` 函数
    
- **返回类型**：`char*`，返回内部指针（注意：调用者不应 `delete` 这个指针，因为它由 `String` 对象管理）
    

## 七、完整代码模板

```cpp

// string.h
#ifndef _STRING_H_
#define _STRING_H_
#include <cstring>
class String {
public:
    // 构造函数
    String(const char* cstr = 0);
    
    // 拷贝构造函数
    String(const String& str);
    
    // 拷贝赋值运算符
    String& operator=(const String& str);
    
    // 析构函数
    ~String();
    
    // 辅助函数
    char* get_c_str() const { return m_data; }
    
private:
    char* m_data;
};
// 构造函数
inline String::String(const char* cstr)
{
    if (cstr) {
        m_data = new char[strlen(cstr) + 1];
        strcpy(m_data, cstr);
    } else {
        m_data = new char[1];
        *m_data = '\0';
    }
}
// 拷贝构造函数
inline String::String(const String& str)
{
    m_data = new char[strlen(str.m_data) + 1];
    strcpy(m_data, str.m_data);
}
// 拷贝赋值运算符
inline String& String::operator=(const String& str)
{
    if (this == &str) return *this;   // 自我赋值检测
    delete[] m_data;                   // 释放旧资源
    m_data = new char[strlen(str.m_data) + 1];
    strcpy(m_data, str.m_data);
    return *this;                      // 返回当前对象引用
}
// 析构函数
inline String::~String()
{
    delete[] m_data;
}
#endif
```
## 八、知识小结

### 8.1 核心概念速查表

|知识点|核心内容|关键要点|
|---|---|---|
|**字符串类设计**|内部存放指针，动态分配内存存储字符串内容|使用指针而非固定数组，避免大小限制；对象本身仅占 4/8 字节|
|**防卫式声明**|头文件中使用 `#ifndef/#define/#endif`|防止头文件被重复包含|
|**构造函数**|接受 `const char*` 参数，默认值 `= 0`|参数加 `const`；无返回类型；需分配空间并拷贝初值；空字符串也要分配 1 字节给 `\0`|
|**析构函数**|释放动态分配的内存|必须使用 `delete[]` 匹配 `new[]`，否则内存泄漏|
|**拷贝构造函数**|从来源端拷贝到新创建的对象|参数必须是 `const` 引用；不能是值传递（会无限递归）|
|**拷贝赋值运算符**|将来源端内容赋给已存在的目的端|先释放自身内存→再分配新内存→拷贝内容；需检查自我赋值；返回 `*this` 支持链式赋值|
|**自我赋值检测**|`if (this == &str) return *this;`|不仅是效率优化，更是正确性保障（防止访问已释放内存）|
|**引用 vs 取地址**|类型名后为引用（`const String&`），对象前为取地址（`&str`）|容易混淆，需根据上下文区分|
|**辅助函数 `get_c_str()`**|返回内部指针|加 `const` 表示不修改数据；简单函数可类内定义|
|**`inline` 函数**|建议编译器将函数内联展开|最终决定权在编译器；复杂函数也可加 `inline`|

### 8.2 三大函数对比

|对比项|拷贝构造函数|拷贝赋值运算符|析构函数|
|---|---|---|---|
|触发时机|新对象创建时（`String s2(s1)`）|已存在对象被赋值时（`s2 = s1`）|对象销毁时|
|函数名|`类名`|`operator=`|`~类名`|
|参数|`const 类名&`|`const 类名&`|无|
|返回类型|无|`类名&`|无|
|是否检查自我赋值|不需要（对象还没创建）|**必须**|不需要|
|是否释放旧资源|不需要（对象还没创建）|**必须**（否则内存泄漏）|**必须**|

### 8.3 关键原则：三/五/零原则

> **三原则**：如果某个类需要用户定义的析构函数、用户定义的拷贝构造函数或用户定义的拷贝赋值运算符，那么它几乎肯定需要全部三个。

- 因为 `String` 类管理动态内存（指针），必须显式定义三大函数
    
- 如果使用现代 C++ 的 `std::string` 或智能指针，则无需手动定义这些函数（零原则）
    

> 📖 **参考**：cppreference —— “因为 C++ 在各种情况下（按值传递/返回、操作容器等）拷贝和拷贝赋值用户定义类型的对象，这些特殊成员函数会被调用。如果它们不是用户定义的，编译器会隐式定义它们。如果类管理一个资源，其句柄是非类类型的原始指针，则不应使用隐式定义的特殊成员函数。”
