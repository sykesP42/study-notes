# C++ 三大函数：拷贝构造、拷贝赋值、析构

> 本文档系统性地讲解了C++中带指针成员的类必须实现的三个特殊成员函数——**拷贝构造函数**、**拷贝赋值运算符**和**析构函数**。这三大函数是C++资源管理（RAII）的核心，正确实现它们才能避免内存泄漏、野指针等严重问题。

## 一、Class的两种经典分类

### 1.1 带指针成员的类 vs 不带指针成员的类

在C++中，类可以根据成员变量是否包含指针分为两类：

|类型|示例|特点|
|---|---|---|
|**不带指针的类 (Class without pointer member)**|复数类（`Complex`）|成员变量都是值类型（如`double real, imag`），编译器默认生成的拷贝行为完全够用|
|**带指针的类 (Class with pointer member)**|字符串类（`String`）|成员变量包含指针（如`char* m_data`），指向动态分配的内存，**必须自己管理资源**|

### 1.2 为什么String类需要用指针？

字符串的长度是不固定的——`"hello"`只有5个字符，而`"hello world"`有11个字符。如果使用固定大小的数组（如`char data[100]`），要么浪费大量内存，要么无法存储更长的字符串。

使用**动态分配的指针**则灵活得多：需要多长就分配多长，既节省内存又能容纳任意长度的字符串。

### 1.3 测试程序与三大函数的触发时机

假设我们有以下测试代码：

cpp

String s1();             // 调用默认构造函数（创建空字符串）
String s2("hello");      // 调用带参构造函数
String s3(s1);           // 调用拷贝构造函数 —— s3首次创建，以s1为蓝本
s3 = s2;                 // 调用拷贝赋值运算符 —— s3已存在，被重新赋值

**关键区别**：

- **拷贝构造**：对象**首次创建**时调用（如`String s3(s1)`）
    
- **拷贝赋值**：对象**已经存在**，被重新赋值时调用（如`s3 = s2`）
    

### 1.4 为什么带指针的类必须自己写三大函数？

编译器会为每个类自动生成默认版本的拷贝构造函数和拷贝赋值运算符，执行**按位拷贝（bitwise copy）**——简单地把每个字节复制过去[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)[](https://cppreference.dev/w/cpp/language/copy_assignment)。

- **对于不带指针的类（如`Complex`）**：按位拷贝完全够用。`double real`和`double imag`被忠实地复制到新对象，两个对象完全独立。
    
- **对于带指针的类（如`String`）**：按位拷贝会导致**严重问题**——两个对象的指针指向**同一块内存**。这不是真正的拷贝，而是**浅拷贝（shallow copy）**。
    

**浅拷贝的后果**：

1. 修改一个对象的内容会影响另一个对象（数据别名）
    
2. 当一个对象被销毁时释放了内存，另一个对象的指针变成**野指针**，访问会导致程序崩溃
    

> **核心结论**：只要类带有指针成员，**必须自己编写**拷贝构造函数、拷贝赋值运算符和析构函数，不能使用编译器默认版本。[](https://cppreference.dev/w/cpp/language/rule_of_three)

### 1.5 Big Three（三大函数）

对于带指针的类，必须自己实现的三个核心特殊成员函数[](https://cppreference.dev/w/cpp/language/rule_of_three)：

|函数|声明形式|作用|
|---|---|---|
|**拷贝构造函数**|`String(const String& str);`|以现有对象为蓝本创建新对象|
|**拷贝赋值运算符**|`String& operator=(const String& str);`|将已存在对象的值赋给另一个已存在对象|
|**析构函数**|`~String();`|对象生命周期结束时释放动态分配的内存|

> 📖 **参考**：cppreference 三/五/零原则 —— “如果某个类需要用户定义的析构函数、用户定义的拷贝构造函数或用户定义的拷贝赋值运算符，那么它几乎肯定需要全部三个。”[](https://cppreference.dev/w/cpp/language/rule_of_three)

## 二、三大函数详解

### 2.1 构造函数：字符串的创建与初始化

构造函数负责为字符串分配内存并初始化内容。

cpp

inline String::String(const char* cstr = 0)
{
    if (cstr) {
        // 情况1：传入有效字符串
        m_data = new char[strlen(cstr) + 1];  // +1 是为了存放结束符 '\0'
        strcpy(m_data, cstr);
    }
    else {
        // 情况2：传入空指针（未指定初值）
        m_data = new char[1];   // 分配1个字节
        *m_data = '\0';         // 设为空字符串
    }
}

**关键知识点**：

- **C/C++字符串的存储方式**：字符串末尾有一个结束符`\0`（空字符），通过遍历到`\0`来计算字符串长度。
    
- **分配空间的计算**：`new char[strlen(cstr) + 1]` —— `+1`是为结束符`\0`预留空间。如果忘记加1，`strcpy`会越界写入，导致**未定义行为**。
    
- **空字符串的处理**：即使没有传入任何内容，也需要为`\0`分配1个字节，形成一个真正的空字符串。
    

> 📖 **参考**：cppreference 构造函数 —— “构造函数是用于初始化类对象的特殊成员函数。”[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)

### 2.2 析构函数：内存释放与清理

析构函数是对象生存期终结时调用的特殊成员函数，其目的是释放对象在其生存期内可能获取的资源。[](https://en.cppreference.com/mwiki/index.php?oldid=170603&title=cpp/language/destructor)

cpp

inline String::~String()
{
    delete[] m_data;   // 释放构造函数中用 new[] 分配的内存
}

**为什么需要析构函数？**

- 对于`Complex`这样的类，成员变量是值类型，对象销毁时无需特殊清理。
    
- 但对于`String`这样的类，指针`m_data`指向的是**动态分配的内存**。如果不释放，这块内存将永远无法被回收，造成**内存泄漏**。
    

**析构函数的调用时机**[](https://en.cppreference.com/mwiki/index.php?oldid=170603&title=cpp/language/destructor)：

- **栈对象**：当对象离开其作用域（`{}`）时，析构函数被**自动调用**。
    
- **堆对象**：使用`delete`手动释放指针时，析构函数被调用。
    

cpp

{
    String s1;           // 栈对象
    String s2("hello");  // 栈对象
    String* p = new String("hello");  // 堆对象
    // ...
    delete p;            // 必须手动 delete，触发 p 的析构函数
}   // 离开作用域，s1 和 s2 的析构函数自动被调用

> ⚠️ **警告**：必须使用`delete[]`释放`new[]`分配的内存。如果写成`delete m_data`（没有方括号），只会释放第一个字符，导致**内存泄漏**和**未定义行为**。

> 📖 **参考**：cppreference 析构函数 —— “析构函数是对象生存期终结时调用的特殊成员函数。析构函数的目的是释放对象可能在它的生存期间获得的资源。”[](https://zh.cppreference.com/index.php?title=cpp/language/destructor&variant=zh-hk)

### 2.3 拷贝构造函数：深拷贝的实现

拷贝构造函数是用一个同类型对象来初始化另一个对象。[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)

cpp

inline String::String(const String& str)
{
    // 分配足够空间容纳 str 的内容（含结束符）
    m_data = new char[strlen(str.m_data) + 1];
    // 将内容拷贝过来
    strcpy(m_data, str.m_data);
}

**语法要点**：

- 函数名与类名相同（因为它是构造函数）
    
- 参数必须是**同类的引用**，并且要加`const`（因为蓝本对象不会被修改）[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)
    
- 参数为什么必须是引用？如果是按值传递（`String(const String str)`），传递实参时**本身就又调用了拷贝构造函数**，形成无限递归，编译失败。[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)
    

**两种调用方式（完全等价）**：

cpp

String s2(s1);   // 直接初始化 (direct-initialization)
String s2 = s1;  // 拷贝初始化 (copy-initialization)

两种写法含义完全相同，都是调用拷贝构造函数。[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)

**深拷贝 vs 浅拷贝**：

||浅拷贝（编译器默认）|深拷贝（自己实现）|
|---|---|---|
|操作|复制指针的值（地址）|分配新内存，复制内容|
|结果|两个指针指向同一块内存|两个指针指向各自独立的内存|
|问题|修改一个影响另一个；重复释放导致崩溃|安全、独立|

> 📖 **参考**：cppreference 拷贝构造函数 —— “拷贝构造函数是用同 class 类型的实参调用的构造函数，它复制实参的内容而不修改实参。”[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)“当对象从另一个相同类型的对象初始化时，调用拷贝构造函数。”[](https://cppreference.dev/w/cpp/language/copy_constructor#Implicitly-defined_copy_constructor)

### 2.4 拷贝赋值运算符：深度赋值的实现

拷贝赋值运算符负责将一个已存在对象的内容复制到另一个已存在对象。[](https://cppreference.dev/w/cpp/language/copy_assignment)

cpp

inline String& String::operator=(const String& str)
{
    // 第一步：检测自我赋值
    if (this == &str) {
        return *this;   // 如果是自己给自己赋值，直接返回
    }
    
    // 第二步：释放自己原来的内存
    delete[] m_data;
    
    // 第三步：分配新内存并拷贝内容（深拷贝）
    m_data = new char[strlen(str.m_data) + 1];
    strcpy(m_data, str.m_data);
    
    return *this;   // 返回左操作数的引用，支持链式赋值
}

**经典三步走**：

|步骤|操作|目的|
|---|---|---|
|**① 自我检测**|`if (this == &str)`|防止自己给自己赋值时崩溃|
|**② 释放旧资源**|`delete[] m_data`|避免内存泄漏|
|**③ 分配新资源并拷贝**|`new[]` + `strcpy`|实现深拷贝|

**语法要点**[](https://cppreference.dev/w/cpp/language/copy_assignment)[](https://zh.cppreference.com/index.php?title=cpp/language/copy_assignment&variant=zh-sg)：

- 函数名是`operator=`（重载赋值运算符）
    
- 参数是同类`const`引用（只读输入）
    
- 返回类型是**引用**（`String&`），返回`*this`以支持链式赋值如`a = b = c`
    

> 📖 **参考**：cppreference 拷贝赋值运算符 —— “拷贝赋值运算符是名字为 operator= 的非模板非静态成员函数，它提供一个相同类类型实参就能调用，并且在不修改实参的情况下复制该实参的内容。”[](https://zh.cppreference.com/index.php?title=cpp/language/copy_assignment&variant=zh-sg)

### 2.5 自我赋值检测 —— 为什么必不可少？

**自我赋值**指将对象赋值给自身，例如`s2 = s2`，或更隐蔽的情况（如通过指针或引用：`s2 = *ptr`，而`ptr`恰好指向`s2`）。

**如果不做自我赋值检测，会发生什么？**

cpp

// 错误的实现（没有自我赋值检测）
String& String::operator=(const String& str)
{
    delete[] m_data;                           // 第一步：释放自己
    m_data = new char[strlen(str.m_data) + 1]; // 第二步：访问 str.m_data
    strcpy(m_data, str.m_data);
    return *this;
}

当执行`s2 = s2`时：

1. `delete[] m_data` —— 释放了`s2`唯一的内存块
    
2. `strlen(str.m_data)` —— 此时`str`就是`s2`，`str.m_data`指向的是**已被释放的内存**
    
3. 访问已释放的内存 → **未定义行为（Undefined Behavior）**，程序可能崩溃或产生随机结果
    

**自我赋值检测不仅是效率优化，更是正确性保障**：

- **效率**：检测到自我赋值后直接返回，避免了不必要的内存操作
    
- **正确性（关键）**：如果不做检测，自我赋值会导致程序崩溃
    

> 📖 **参考**：cppreference 三/五/零原则示例代码中明确展示了自我赋值检测的实现。[](https://cppreference.dev/w/cpp/language/rule_of_three)

### Big Three 经典实现模板

cpp

class String {
public:
    // 构造函数
    String(const char* cstr = nullptr) {
        if (cstr) {
            m_data = new char[strlen(cstr) + 1];
            strcpy(m_data, cstr);
        } else {
            m_data = new char[1];
            *m_data = '\0';
        }
    }
    
    // 析构函数
    ~String() {
        delete[] m_data;
    }
    
    // 拷贝构造函数
    String(const String& str) {
        m_data = new char[strlen(str.m_data) + 1];
        strcpy(m_data, str.m_data);
    }
    
    // 拷贝赋值运算符
    String& operator=(const String& str) {
        if (this == &str) return *this;   // 自我赋值检测
        delete[] m_data;                   // 释放旧资源
        m_data = new char[strlen(str.m_data) + 1];
        strcpy(m_data, str.m_data);
        return *this;
    }
    
private:
    char* m_data;   // 指向动态分配的字符数组
};

### 三/五/零原则

> **三原则**：如果某个类需要用户定义的析构函数、用户定义的拷贝构造函数或用户定义的拷贝赋值运算符，那么它几乎肯定需要全部三个。[](https://cppreference.dev/w/cpp/language/rule_of_three)

- **C++98/03 三原则**：需要析构 → 需要拷贝构造 + 拷贝赋值
    
- **C++11 五原则**：增加了移动构造函数和移动赋值运算符
    
- **零原则**：尽可能使用现代C++的资源管理类（如`std::string`、`std::vector`、智能指针），让编译器自动生成所有特殊成员函数
    

> 📖 **参考**：cppreference 三/五/零原则 —— “因为 C++ 在各种情况下（按值传递/返回、操作容器等）拷贝和拷贝赋值用户定义类型的对象，这些特殊成员函数会被调用。如果它们不是用户定义的，编译器会隐式定义它们。如果类管理一个资源，其句柄是非类类型的原始指针，则不应使用隐式定义的特殊成员函数。”
